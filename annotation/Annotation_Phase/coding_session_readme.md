## 1. Before you start coding

I would like us to go through the taxonomy guide (see /Preparation_Phase in github) together before starting.

Our first research question concerns the percentage of posts discussing each topic among eligible posts mentioning *You Can See Everything*. We are classifying **what each post mainly discusses**, not its sentiment or simply which movie it mentions.

The guide contains six categories (more details in taxonomy guide):

- **REACT:** General reactions or opinions
- **CONTENT:** Story, plot, characters, or themes
- **CRAFT:** Filmmaking and artistic elements
- **VIEWING:** Screenings and viewing experiences
- **CIRC:** Distribution, publicity, and commercial performance
- **HUMOR:** Jokes, memes, or humorous commentary

During our orientation, we'll practice with the 200 pilot examples in the open_coding file, particularly the distinctions between general reactions and specific observations, and between screenings and box-office performance.

We'll use **version 1.0 of the guide** for this coding round. If we need to change a definition, I'll update the guide and share the new version with everyone before coding resumes.

## 2. Your individual coding task

Each of you will receive a separate Excel workbook (`coder_YOUR_NAME.xlsx`).

1. Open your workbook and read the instructions on the first tab.
2. Go to the **Final coding** tab.
3. Read the full `post_text` for each assigned post.
4. Select **exactly one topic** from the dropdown in the `topic_code` column.
5. If you're unsure between two categories, explain why in `uncertain_or_reason`.
6. Keep the original `post_id` and `post_text` unchanged.

**Please code independently.** Only use the text provided in your worksheet. Do not open links, inspect images, or consult anyone else's classifications. This is necessary for us to measure agreement properly.

### Posts that might not be eligible

Some collected posts might mention the movie only in passing, be off-topic, be in another language, or refer to an older adaptation of *Sense and Sensibility*.

If you encounter one of these, write **ELIGIBILITY REVIEW** in `uncertain_or_reason`, along with a short explanation. If you can still identify a reasonable topic, assign that topic as well.

I'll review these cases before our final analysis. Some questionable posts have already been flagged during data collection, but please flag any additional ones you notice.
